# TelefonansageDirekt

IP-Symcon-9-Modul für ausgehende SIP-Anrufe mit individueller Sprachnachricht, AWS Polly und FIFO-Warteschlange.

## Branch-Konzept

- `main`: stabile, getestete Versionen
- `develop`: laufende Entwicklung und Testversionen

## Aktueller Ausgangsstand

Die bestätigte Ausgangsversion ist `TelefonAnsageModul_Queue_2SekundenPause_Instanzauswahl.zip` aus dem Chat. Die Moduldateien werden anschließend in der IP-Symcon-Bibliotheksstruktur eingecheckt.
