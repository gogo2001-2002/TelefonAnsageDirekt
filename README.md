# TelefonansageDirekt

IP-Symcon-9-Modul für ausgehende SIP-Anrufe mit individueller Sprachnachricht, AWS Polly und FIFO-Warteschlange.

## Branch-Konzept

- `main`: stabile, getestete Versionen
- `develop`: laufende Entwicklung und Testversionen

Ausgangsstand: `TelefonAnsageModul_Queue_2SekundenPause_Instanzauswahl.zip`. Der vollständige Modulquellcode muss aus dieser ZIP übernommen werden.
